Channel Hub

Channel Hub is a private dashboard that its owner runs on their own computer to see, in one place, the statistics of the YouTube channels the owner manages: subscribers, views, watch time and upcoming scheduled videos.

It only reads data (YouTube Data API and YouTube Analytics API, read-only scopes). It does not upload, edit or delete anything on YouTube, and it is not offered to the public.
